# Supply-Chain-Analysis-Tableau
Interactive supply chain analysis dashboard created using Tableau to visualize key business and operational insights.

## Project Overview

This project presents an interactive Supply Chain Analysis dashboard developed using Tableau. The project focuses on understanding inventory, order trends, delivery performance, supplier performance, lead times, quality scores, and supplier costs.

The dashboard is divided into two analytical views: Product Analysis and Performance Dashboard.

## Objectives

- Analyze inventory levels and stock movements
- Understand order trends over time
- Evaluate delivery performance by status
- Compare supplier delivery and quality performance
- Analyze supplier lead times and costs
- Identify areas that may require operational attention

## Dashboard 1: Product Analysis

The Product Analysis dashboard provides an overview of inventory and order-related metrics.

### Key Areas Covered

- Customer sales orders
- Quantity and stock movements
- Quantity on hand by product
- Delivery performance by status
- Order trends over time

### Key Metrics

- Total Quantity
- Stock Movements
- Quantity
- Quantity on Hand
- Customer Sales Orders

## Dashboard 2: Performance Dashboard

The Performance Dashboard focuses on supplier and operational performance.

### Key Areas Covered

- Supplier on-time delivery rate
- Supplier quality score
- Lead time comparison
- Supplier cost analysis
- Orders per supplier

### Key Metrics

- Average Lead Time
- Minimum Delivery Time
- Average On-Time Delivery Rate
- Average Quality Score
